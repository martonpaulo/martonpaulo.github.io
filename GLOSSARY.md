# Glossary

The words this site and its code use for one thing each.

| Term        | Definition                                                                                                                             | Do not write               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| Project     | One entry of `db/projects.json`: a product, library, typeface or experiment the site presents.                                         | work, item, portfolio item |
| Card        | A Project's tile in a list, with its name, tagline, artwork and one link to its page.                                                  | tile (in prose), box       |
| Kind        | One value of `kinds` in a Project, such as `web` or `macos`; the site filters the list by Kind.                                        | category, type             |
| Featured    | A Project shown on the home page, which needs artwork.                                                                                 | highlighted, pinned        |
| Status      | Whether a Project is `active`, `discontinued` (retired, still listed last with a badge) or `archived`.                                 | state                      |
| Archive     | `https://archive.martonpaulo.com/`, the noindex site that keeps retired web Projects' frozen builds (`martonpaulo/portfolio-archive`). | graveyard, old projects    |
| Live link   | A Project's `links.live`, the address the product answers at; `/p/<slug>/` redirects to it.                                            | demo link, URL             |
| Share image | The one generated Open Graph image, `/og/site.png`, every page links to.                                                               | OG card, thumbnail         |
