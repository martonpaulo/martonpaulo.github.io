# Glossary

The words this site and its code use for one thing each.

| Term         | Definition                                                                                                                                      | Do not write               |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| Project      | One entry of `db/projects.json`: a product, library or typeface the site presents.                                                              | work, item, portfolio item |
| Card         | A Project's tile in a list, with its name, tagline, artwork and one link to its page.                                                           | tile (in prose), box       |
| Kind         | One value of `kinds` in a Project: the platform it runs on, such as `web` or `macos`, never a genre; each Kind is a tab.                        | category, type             |
| Featured     | One of the six current Projects with the highest score, shown on the home page; it needs artwork.                                               | highlighted, pinned        |
| Status       | Whether a Project is `active`, `discontinued` (retired, listed under Earlier work) or `archived`.                                               | state                      |
| Earlier work | The tab of retired, old and study projects, `/projects/earlier/`, listed from `db/earlier.json` and dated by the years of real work.            | past projects, archive tab |
| Archive      | `archive.martonpaulo.com`, the noindex site that keeps each Earlier work build at `/<slug>/`, with nothing at its root (`martonpaulo/archive`). | graveyard, old projects    |
| Live link    | A Project's `links.live`, the address the product answers at; `/p/<slug>/` redirects to it.                                                     | demo link, URL             |
| Share image  | The one generated Open Graph image, `/og/site.png`, every page links to.                                                                        | OG card, thumbnail         |
