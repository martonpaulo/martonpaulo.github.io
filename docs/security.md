# Security

The answer to each item of the `bench-project-standards` skill's `references/security-standard.md`.
The site is a static web app: Astro builds HTML from the JSON files in `db/` and GitHub Pages serves
it behind the owner-managed Cloudflare proxy (`docs/hosting.md`). It has no API, no database, no
server of its own, no sign-in, no form and no upload. Checked 2026-11-26
([#46](https://github.com/martonpaulo/martonpaulo.github.io/issues/46)).
